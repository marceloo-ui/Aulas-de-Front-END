São Paulo — Uma empresa brasileira teria iniciado, em uma situação completamente fictícia, um projeto experimental para utilizar pombos-correio na entrega de pequenas encomendas dentro de áreas urbanas. Batizado de “Pombo Express”, o projeto teria como objetivo criar uma alternativa rápida para transportar documentos, pequenos objetos e correspondências entre pontos próximos da cidade. De acordo com os responsáveis pelo projeto fictício, os animais seriam treinados durante várias semanas para reconhecer diferentes pontos de entrega. Cada pombo carregaria uma pequena cápsula presa às patas, contendo a encomenda.
